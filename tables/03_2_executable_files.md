# Размеры исполняемых файлов и время выполнения программ

Замеры проводились командами:
```bash
time for i in $(seq 1 10); do ./src/bench_COMPILER_FLAG > /dev/null; done
```

```bash
ls -la src/bench_clang_O* 
```

Время на один запуск рассчитано как суммарное `real` / 10.
