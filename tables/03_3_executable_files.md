# Размеры исполняемых файлов и время выполнения программ

Замеры проводились командами:
```bash
time for i in $(seq 1 10); do ./src/bench_COMPILER_FLAG > /dev/null; done
```

```bash
ls -la src/bench_icx_O* 
```

Время на один запуск рассчитано как суммарное `real` / 10.

## Intel ICX

| Флаг | Назначение | Размер (байт) | real (10 runs) | real (1 run) | user (1 run) | sys (1 run) |
|---|---|---|---|---|---|---|
| `-O0` | Без оптимизации | 16 936 | 0m0.040s | ~4.0 мс | ~0.6 мс | ~3.6 мс |
| `-O2` | По скорости | 16 984 | 0m0.035s | ~3.9 мс | ~0.4 мс | ~3.7 мс |
| `-Os` | По размеру | 16 984 | 0m0.036s | ~3.7 мс | ~0.4 мс | ~3.5 мс |
