# Таблица оптимизаций (-O2)

Ассемблерный код с оптимизацией `-O2` для каждого компилятора.

| Оптимизация | GCC -O2 | Clang -O2 | ICX -O2 |
|---|---|---|---|
| `i3 = 1+2` | `movl $3, i3` | `movl $3, i3` | `movl $3, i3` |
| `flt_1 = 2.4+6.3` | загрузка из `.rodata` | `movabsq $4621...` | `movabsq $4621...` |
| `j2 = i + 0` | простой `mov` | простой `mov` | простой `mov` |
| `k2 = i / 1` | простой `mov` | простой `mov` | простой `mov` |
| `i4 = i * 1` | простой `mov` | простой `mov` | простой `mov` |
| `i5 = i * 0` | `movl $0, i5` | `movl $0, i5` | `movl $0, i5` |
| `k2 = 4 * j5` | `sall $2, %eax` | `shll $2, %eax` | `shll $2, %eax` |
| `k3=1; k3=1;` | одна инструкция `mov` | одна инструкция `mov` | одна инструкция `mov` |
| `dead_code` | только `ret` | только `retq` | только `retq` |
| `unnecessary_loop` | цикл убран + tail call | цикл убран + tail call | цикл убран + tail call |
| `loop_unrolling` | цикл сохранён | цикл сохранён | **цикл полностью развёрнут** |
| инвариант `j*k` | вынесен из цикла | вынесен из цикла | вынесен + частичная размотка |
| `ivector4[i]=i*2` | константа в `.rodata` | `movabsq` константа | `movabsq` константа |
| деление в `m3` | `idivl i3` | `idivl i3` | **`imulq` + `shrq` (без деления!)** |
| инициализация FPU | отсутствует | отсутствует | **`stmxcsr`/`ldmxcsr`** |
