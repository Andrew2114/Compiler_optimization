# Версии компиляторов

| Компилятор | Версия | Команда компиляции (флаг оптимизации) |
|---|---|---|
| GCC | 13.3.0 (Ubuntu 13.3.0-6ubuntu2~24.04.1) | `gcc [флаг] -DNO_ZERO_DIVIDE` |
| Clang | 18.1.3 (Ubuntu clang version 18.1.3) | `clang [флаг] -DNO_ZERO_DIVIDE` |
| Intel ICX | 2026.0.0 (Intel oneAPI DPC++/C++ Compiler) | `icx [флаг] -DNO_ZERO_DIVIDE` |

## Флаги оптимизации

| Флаг | Назначение |
|---|---|
| `-O0` | Без оптимизации (режим отладки) |
| `-O2` | Оптимизация по скорости |
| `-Os` | Оптимизация по размеру файла |
| `-S` | Генерация ассемблерного кода вместо бинарного файла |
| `-DNO_ZERO_DIVIDE` | Отключение блока деления на ноль в исходнике |
