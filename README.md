# Учебная практика по теме: "Сравнение и анализ оптимизаций компиляторв"

## ***Цель практики***: Исследование и сравнительный анализ эффективности оптимизаций компиляторов GCC, CLang и Intel C на примере программы optbench.c.

### Задачи
1. Описать среду исследования (ОС, архитектура, версии компиляторов).
2. Выполнить компиляцию тестовой программы с уровнями оптимизации `-O0`, `-O2`, `-Os`.
3. Произвести замеры размера исполняемых файлов и времени выполнения.
4. Скомпилировать ассемблерный код и составить сравнительные таблицы.
5. Провести анализ применённых оптимизаций.
6. Сравнить компиляторы между собой и сформулировать выводы.

---

## Уровни оптимизации и флаги компиляции

| Уровень | Флаг | Назначение |
|---------|------|-------------|
| Без оптимизаций | `-O0` | Максимально прямолинейный код, удобно для отладки |
| Оптимизация по скорости | `-O2` | Все основные оптимизации (рекомендуемый уровень) |
| Оптимизация по размеру | `-Os` | Компромисс: меньший размер ценой небольшого замедления |

## Компиляторы
- GCC 13.3.0
- Clang 18.1.3
- Intel ICX 2026.0.0
